Proyecto, Objetivos y Metodología

Fundamentación académica y fases de desarrollo del sistema IoT.

Problema y Justificación

La variabilidad climática de la región somete a los cultivos a estrés hídrico y térmico debido a controles manuales ineficientes.

Este proyecto plantea una solución basada en Internet de las Cosas (IoT) y Analítica de Datos para automatizar umbrales y sustentar decisiones agronómicas operativas.

Objetivos del Proyecto

General: Desarrollar un sistema de gestión del conocimiento integrando telemetría IoT (ESP32) y herramientas BI (Power BI) para optimizar el control microclimático.

  • Diseñar e implementar una red de sensores DHT22 y actuadores con ESP32.
  • Estructurar un ETL robusto para almacenar lecturas masivas.
  • Desarrollar un dashboard para la extracción de conocimientos y decisiones.

Metodología (CRISP-DM)

FASES 1-2

Negocio y Datos

Definición de variables telemétricas y umbrales térmicos por cultivo: Cilantro (70%), Frijol (60%) y Lentejas (50%).

FASES 3-4

Preparación y Modelado

Depuración de valores nulos (NaN) del sensor DHT22. Diseño del modelo relacional y simulación de 1,000,000 registros.

FASES 5-6

Evaluación y Despliegue

Despliegue de la API REST en Python (Flask) para captura de datos y publicación del Dashboard en Power BI Service.
